# 🌿 PlantScan — Plant Disease Detection System

A beginner-friendly machine learning project that detects plant leaf diseases from images using a CNN (Convolutional Neural Network) model built with TensorFlow/Keras and served through a Flask web application.

---

## 📋 Project Overview

| Feature        | Details                                    |
|----------------|--------------------------------------------|
| **Dataset**    | PlantVillage                               |
| **Model**      | Custom CNN (3 conv blocks + dense layers)  |
| **Backend**    | Python 3.9+ / Flask                        |
| **Frontend**   | HTML5, CSS3, Vanilla JavaScript            |
| **Classes**    | Healthy, Early Blight, Late Blight, Leaf Mold |
| **Input Size** | 128×128 RGB images                         |

## 🚀 Setup & Installation

### Step 1 — Clone / Download the Project

```bash
cd your-projects-folder
```

### Step 2 — Create a Virtual Environment (Recommended)

```bash
python -m venv venv

# On macOS/Linux:
source venv/bin/activate

# On Windows:
venv\Scripts\activate
```

### Step 3 — Install Dependencies

```bash
pip install -r requirements.txt
```

> **Note:** TensorFlow can be large (~500MB). On slow connections, use `tensorflow-cpu` instead.

### Step 4 — Run the App (Demo Mode)

Without a trained model, the app runs in **Demo Mode** (random predictions for UI testing):

```bash
python app.py
```

Open your browser at **http://localhost:5000**

## 🧠 Training the Model

### Step 1 — Download the Dataset

Get the PlantVillage dataset from Kaggle:
👉 https://www.kaggle.com/datasets/emmarex/plantdisease

### Step 2 — Organize Dataset Folder

Create a `dataset/` folder in the project root:

```
dataset/
  train/
    Healthy/           ← ~500–1000 images
    Early_Blight/      ← ~500–1000 images
    Late_Blight/       ← ~500–1000 images
    Leaf_Mold/         ← ~500–1000 images
  val/
    Healthy/           ← ~100–200 images
    Early_Blight/      ← ~100–200 images
    Late_Blight/       ← ~100–200 images
    Leaf_Mold/         ← ~100–200 images
```

**Tip:** Use an 80/20 split — 80% of images go to `train/`, 20% to `val/`.

### Step 3 — Train the Model

```bash
python train_model.py
```

Training takes **10–30 minutes** depending on hardware. The model auto-saves to `model/plant_disease_model.h5`.

### Step 4 — Run the Full App

```bash
python app.py
```

## 🛠️ CNN Architecture

```
Input (128×128×3)
    ↓
Conv Block 1: Conv2D(32) → Conv2D(32) → MaxPool → BatchNorm → Dropout(0.25)
    ↓
Conv Block 2: Conv2D(64) → Conv2D(64) → MaxPool → BatchNorm → Dropout(0.25)
    ↓
Conv Block 3: Conv2D(128) → Conv2D(128) → MaxPool → BatchNorm → Dropout(0.4)
    ↓
Flatten
    ↓
Dense(256) → BatchNorm → Dropout(0.5)
    ↓
Dense(4, softmax) → Output probabilities
```

## ❓ Troubleshooting

| Problem | Solution |
|---------|----------|
| `ModuleNotFoundError: flask` | Run `pip install -r requirements.txt` |
| Port already in use | Change `port=5000` in `app.py` |
| Model not found warning | Run `train_model.py` first, or use Demo Mode |
| Slow training | Use `tensorflow-cpu`, reduce `EPOCHS`, or reduce dataset size |
| CUDA errors | Switch to CPU: `tensorflow-cpu` |
